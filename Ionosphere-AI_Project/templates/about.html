ABOUT THE PROJECT

Intelligence for the Ionosphere.

Ionosphere-AI is a machine-learning based Total Electron Content prediction and visualization system designed to transform complex ionospheric observations into an understandable scientific experience.

🌌 Our Mission

The ionosphere constantly changes with geographic location and time. Understanding these changes is important for technologies that depend on signals travelling through the Earth's upper atmosphere.

This project uses historical TEC observations and machine learning to estimate TEC values for a selected location and time.

PROJECT GOAL

Convert complex scientific data into an intuitive prediction and visualization platform.
