### 3. Machine Learning Model Development

IBM BOB-assisted development support was used while developing the machine learning prediction workflow.

The project uses a hybrid approach based on:

- **ExtraTrees Regressor**
- **Distance-Based K-Nearest Neighbors (KNN)**

The machine learning workflow includes:

1. Loading the processed TEC dataset.
2. Selecting and preparing prediction features.
3. Training the ExtraTrees model.
4. Training the Distance KNN model.
5. Combining the prediction approach.
6. Evaluating the model using Mean Absolute Error (MAE).

The final system generates a TEC prediction based on the user's geographic location and selected date and time.
